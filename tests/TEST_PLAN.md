## 手工测试场景（UI 交互层）

### 辩论模式 (debate)

**T-MAN-DEB-01: 5人全员辩论**
- 浏览器中：首页选择辩论模式，输入「太空探索值得投入多少资源？」
- @所有 5 位成员，点击「开始辩论」
- 检查点：
  - 3 轮完整流程（开场陈述→交叉辩论→总结）
  - 每轮所有成员发言
  - 芒格不说「我没什么要补充的」
  - 马斯克不机械套用「白痴指数」「物理定律」
  - 主持人总结客观中立

**T-MAN-DEB-02: 芒格发言质量专项**
- 问题：「加密货币是否应该被全面禁止？」
- 成员：munger, paulgraham
- 检查点：芒格给出实质性观点，不用沉默回应

**T-MAN-DEB-03: 马斯克发言质量专项**
- 问题：「如何平衡工作和生活？」
- 成员：musk, karpathy
- 检查点：马斯克有变化和创意，不每轮重复相同词汇

**T-MAN-DEB-04: 辩论模式终止**
- 操作：辩论进行中点击「终止讨论」
- 检查点：讨论停止，历史记录中状态变为「已终止」

### 聊天模式 (chat)

**T-MAN-CHAT-01: 聊天 follow-up 完整流程**
- 首页选择聊天模式，输入「如何高效管理个人财务？@查理·芒格」
- 等待芒格回复 → 输入「能举一个具体的投资案例吗？」
- 等待回复 → 再输入「@埃隆·马斯克 你同意芒格的观点吗？」
- 检查点：
  - 所有回复在同一讨论下
  - 历史记录只有一条，包含全部消息
  - 输入框在每次 AI 回复后可用
  - 不出现「API Key 丢失」错误

**T-MAN-CHAT-02: @mention 下拉菜单**
- 操作：聊天输入框输入「@」
- 检查点：
  - 只显示已参与的成员
  - 上下箭头切换选项
  - Enter 选择，Escape 关闭

**T-MAN-CHAT-03: 多成员聊天初始 + follow-up**
- 问题：「@查理·芒格 @埃隆·马斯克 面对重大决策时，如何克服选择困难症？」
- 检查点：两人分别给出不同角度的回答
- follow-up：「@查理·芒格 你同意吗？」→ 芒格有新回复

**T-MAN-CHAT-04: 历史记录恢复会话**
- 操作：在历史记录中找到运行中的聊天讨论，点击「继续讨论」
- 检查点：
  - 正确恢复会话
  - 可以继续对话
  - API Key 正常工作

### 边界场景

**T-MAN-EDGE-01: 错误 API Key**
- 操作：设置页面配置一个错误的 API Key，发起讨论
- 检查点：显示明确错误信息，页面不崩溃

**T-MAN-EDGE-02: 辩论模式只选 1 人**
- 操作：只选 1 人，点击开始辩论
- 检查点：报错「辩论模式至少需要选择2位成员」

**T-MAN-EDGE-03: 超长对话**
- 操作：持续 follow-up 聊天超过 300 条消息
- 检查点：不崩溃，旧消息被截断
