# Scram（滚蛋计划）- iOS App 交互与视觉设计文档

## 1. 信息架构 (IA)

### 1.1 导航结构

采用 **底部 Tab Bar**（4 个 Tab）+ 页面内 Stack 导航：

```
Tab Bar
├── 📅 今天 (Today)          ← 首页，跨项目任务列表 + 吐槽
├── 📊 周报 (Weekly)         ← 周结算报告 + 本周统计 + 项目维度
├── 📆 日历 (Calendar)       ← 按周查看的日历视图
└── 📁 项目 (Projects)       ← 项目管理、子任务管理

Stack Navigation（各 Tab 内子页面）
├── Today → 任务详情（点击卡片进入，含吐槽历史）
├── Weekly → 历史周报（点击往期周报进入）
├── Weekly → 周报分享页（生成分享图片）
├── Projects → 设置列表（右上角 ⚙️ 进入：吐槽设置、通知设置、深色模式）
├── Projects → 项目详情（查看子任务列表）
├── Projects → 创建/编辑子任务
├── Calendar → 日期详情（点击日期进入）
└── Calendar → 周结算详情（点击周日标记进入）
```

### 1.2 页面清单

| 页面 | 所属 Tab | 核心功能 | 入口 |
|------|----------|----------|------|
| **今天首页** | Today | 当日任务列表（跨项目混排）、打卡、吐槽气泡 | 默认首页 |
| **任务详情** | Today | 单个任务的备注、历史、延期记录、吐槽历史 | 点击任务卡片 |
| **周报首页** | Weekly | 本周结算报告、完成率、评语、项目维度统计 | Weekly Tab |
| **历史周报** | Weekly | 查看往期周报 | 点击历史列表 |
| **周报分享** | Weekly | 生成周报图片，分享社交媒体 | 点击 [分享] 按钮 |
| **周度日历** | Calendar | 按周查看完成/未完成状态 | Calendar Tab |
| **日期详情** | Calendar | 查看某一天的具体任务完成情况 | 点击日历某天 |
| **项目列表** | Projects | 所有活跃项目卡片，项目进度条 | Projects Tab |
| **项目详情** | Projects | 查看子任务列表、项目统计 | 点击项目卡片 |
| **创建/编辑子任务** | Projects | 表单创建或修改子任务 | 项目详情 "+" / 项目卡片右侧 "+" 按钮 |
| **设置列表** | Projects | 吐槽设置、通知设置、深色模式 | 项目主页右上角 ⚙️ |

### 2.1 首页 - 今日日程

```
│ 🔥 7  ·  💢 3                   │

│                                  │

│                                  │
│ ┌────────────────────────────┐  │
│ │ ⚠️×3  前端重构              │  │
│ │ [日历APP]  14:00  14:00-15:30│  │
│ │ "又见面了，第3次了哦"        │  │
│ │          [补卡]    [延期]    │  │
│ └────────────────────────────┘  │
│                                  │
│ ┌────────────────────────────┐  │
│ │ ⏰  产品方案评审            │  │
│ │ [日历APP]  16:00  16:00-18:00│  │
│ │    还有 2 小时 15 分钟       │  │
│ │              [放弃] [延期]   │  │

│                                  │
├──────────────────────────────────┤

└──────────────────────────────────┘
```

**卡片内容规范**
- 第一行：状态标识 + 任务名称 + 延期次数（仅延期任务，如 `⚠️×3`）
- 第二行：项目标签（颜色标识）+ **开始时间**（如 `10:00`）+ **任务周期**（如 `10:00-12:00`）
- 第三行：额外信息（待展示倒计时 / 延期展示吐槽 / 进行中超时展示吐槽）
- 底部：操作按钮

**延期任务视觉突出**
- 红色渐变背景 + 暗纹纹理（区别于正常卡片白色底）
- 左侧标识为 `⚠️` + `×N` 延期次数
- 吐槽文案以气泡形式叠加在卡片上
- 卡片整体有微妙的呼吸动画（强调存在感）

**各状态卡片差异**

| 状态 | 左侧标识 | 额外内容 | 操作按钮 | 样式 |
|------|---------|---------|---------|------|
| 待开始 | ⏰ 空心圆 | 距离开始倒计时（X小时X分钟，<60分钟显示X分钟） | [放弃] [延期] | 灰色 |
| 进行中 | 🔵 旋转圆点 | 超时则显示吐槽"超时了哦，你完成了么" | [打卡] [放弃] [延期] | 蓝色高亮 |
| 已完成 | ✅ 绿色对勾 | 无 | 无 | 绿色半透明 |
| 延期 | ⚠️ + ×N | 延期次数 + 吐槽文案 | [补卡] [延期] | 红色渐变+纹理+呼吸动效 |
| 已放弃 | ❌ 灰色叉号 | 无 | 无 | 灰色半透明 |

**排序规则**
- 第一排序：开始时间从早到晚
- 第二排序：优先级（高 > 中 > 低）
- 第三排序：创建时间（先创建的排前面）

**交互要点**
- 顶部：日期 + 连续打卡天数（🔥）+ 本周被骂次数（💢）
- **每日吐槽卡片**（日期下方、任务列表上方）：
  - 每次打开 App 或下滑刷新后生成一条新的吐槽文案
  - 吐槽内容基于今日任务数量、当前完成状态、延期任务数、已进行的用户行为综合生成
  - 黄色渐变背景（`#FEF3C7` → `#FDE68A`）+ 🤖 emoji + 16px 圆角
  - 吐槽文案风格随完成度变化：全未完成偏毒舌、部分完成偏调侃、全部完成偏夸奖
  - 文案 72 小时内不重复
  - 点击吐槽文案可复制
- 底部：本周完成率进度条 + 距离周日结算的天数
- 按时间线排列，不分组，不折叠
- 点击卡片主体（非操作按钮区域）：进入任务详情
- 延期任务的吐槽文案点击可展开完整吐槽
- 下滑刷新重新加载数据（同时刷新每日吐槽）
- 空状态：无任务时显示 "连任务都没有，今天打算躺平？"
- 当日全部完成：显示庆祝 + "今天全清，你是时间的统治者"（同时更新吐槽卡片为夸夸文案）

**交互要点**

- 长按里程碑可拖拽排序
- "确认创建" → 批量创建里程碑和子任务，跳转到首页
- "调整后再说" → 保留拆解结果，返回编辑态，用户可手动调整
- AI 分析超时（>30s）→ 提示"AI 思考太慢了，你可以先手动创建，稍后再来查看 AI 结果"
- 网络不可用 → 提示"AI 暂时离线，你可以手动创建子任务"

## 3. 视觉语言

### 3.1 设计风格

**风格关键词**：3D 插画感、柔和渐变、糖果色卡片、圆润饱满、App Store 精品感

- **整体风格**：现代 App Store 精品应用风格，类似参考图中的 3D 微质感 + 柔和渐变
- **色彩基调**：大面积白色/浅灰背景 + 糖果色渐变卡片 + 3D 风格图标
- **渐变使用**：卡片背景、按钮、统计图表大面积使用柔和渐变（紫→青、橙→粉、蓝→紫）

- **反差幽默**：精美可爱的外表 + 毒舌吐槽的内容，形成强烈的反差萌

- **按钮**：
  - 主按钮：渐变填充（`linear-gradient(135deg, #7C3AED, #A78BFA)`）+ 白色文字 + 24px 圆角胶囊 + 柔和阴影
  - 次要按钮：主色描边（2px）+ 主色文字 + 24px 圆角
  - 吐槽弹窗按钮：根据级别使用不同渐变（L1 琥珀渐变、L2 橙红渐变、L3 红色渐变）
  - 文字按钮：无背景 + 主色文字
- **进度条**：12px 高度 + 全圆角 + 渐变填充
- **徽章/标签**：小圆角矩形（12px）+ 糖果色渐变背景 + 白色文字
- **评级徽章**：大尺寸（48x48px）+ 对应等级渐变 + 3D 光效阴影，SSS 级加金色粒子动画
- **分割线**：1px 高度 + `rgba(0,0,0,0.06)` + 左右各留 16px padding
- **图标**：3D 风格 emoji + SF Symbols 组合，关键图标配柔和投影
- **毒舌小助手**：🤖 emoji 加 3D 投影效果，吐槽时表情变化（😤→💢→🔥）

## 5. 设计原则

### 5.1 四条核心原则

**1. 精美的外壳，毒舌的内核**
> UI 保持 App Store 精品级 3D 微质感 + 糖果色渐变，吐槽内容制造反差。这种"看着可爱、说话毒舌"的反差是幽默的核心来源。

**2. 一眼看清状态**
> 任何任务卡片，用户应该在 0.5 秒内知道当前状态。糖果色渐变 + 3D 图标 + 文字三重编码，吐槽气泡是额外信息层。

**3. 操作零思考**
> 打卡只需要一次点击。不弹出多余确认，不需要填写备注（可选）。让用户在走路、喝咖啡的间隙也能完成打卡。

**4. 骂要有分寸**
> 吐槽的核心是"被督促"而不是"被打击"。分级吐槽确保：阴阳怪气让人笑，直接开喷让人不服气，终极清算让人反思——但永远不会让人觉得"这个 App 在针对我"。用户随时可以调低烈度。

### 5.2 差异化设计

| 对比维度 | Things 3 | Todoist | Scram（差异化） |
|----------|----------|---------|-----------------|
| 核心隐喻 | 待办清单 | 任务列表 | **时间块 + 吐槽** |
| 未完成处理 | 手动调整日期 | 自动到期提醒 | **自动延期 + 分级吐槽** |
| 反馈机制 | 无 | 成就系统 | **吐槽 + 周报游戏化评级** |
| 视觉风格 | 极简白 | 功能丰富 | **3D 精品外壳 + 毒舌内容** |
| 打卡方式 | 勾选完成 | 勾选完成 | **计时打卡** |
| 结算周期 | 无 | 自定义过滤 | **周结算（强制）+ SSS 评级** |
| 情感连接 | 工具感 | 工具感 | **像一个毒舌朋友** |

## 6. 动效建议

### 6.1 打卡完成动效

**触发**：点击 [完成] 按钮后

**动画序列**（总时长 ~800ms）：
1. **0-200ms**：按钮缩小 + 渐变到绿色，显示 3D 对勾图标
2. **200-400ms**：卡片背景从白色渐变为薄荷绿渐变（`linear-gradient(135deg, #34D399, #10B981)`）
3. **400-600ms**：粒子庆祝效果（从按钮位置扩散 5-8 个小粒子，3D 风格星星 + 糖果色随机）
4. **600-800ms**：卡片高度收缩 10%（表示"完成归档"），滑入"已完成"分组
5. **同时**：弹出夸夸气泡（渐变背景 + 3D emoji），展示完成反馈文案

**技术实现**：`react-native-reanimated` + `react-native-gesture-handler`

### 6.2 开始打卡动效

**触发**：点击 [开始打卡] 按钮后

**动画序列**（总时长 ~400ms）：
1. **0-150ms**：按钮渐变到蓝色，显示旋转的 3D 计时图标
2. **150-400ms**：卡片背景变为天蓝渐变，底部出现实时计时器（数字跳动动画）

### 6.3 吐槽气泡弹出动效

**触发**：任务超时 / 打开 App 发现延期任务

**动画序列**（总时长 ~500ms）：
1. **0-150ms**：气泡从卡片右上角弹出（缩放 + 弹性动画）
2. **150-300ms**：小三角展开（指向任务图标），背景黄色渐变渐显
3. **300-500ms**：文案逐字打字效果 +  表情变化动画（😤→💢→🔥）

### 6.4 周报评级动效

**触发**：周日结算 / 手动打开周报

**动画序列**（总时长 ~1200ms，类似游戏通关结算）：
1. **0-300ms**：底部弹入（不可直接关闭），背景暗化
2. **300-500ms**：评级徽章从底部弹入 + 旋转出现（如游戏升级效果）
3. **500-700ms**：完成率环形图从 0 动画到目标值 + 数字跳动
4. **700-900ms**：SSS 级全屏光效（金色烟花粒子从屏幕中心扩散）
5. **900-1200ms**：评语逐行淡入，下周目标渐显

### 6.5 列表项滑动

- 左滑：显示 [完成] [再延期] 操作按钮（渐变胶囊按钮）
- 右滑：显示 [备注] [详情] 操作按钮

### 6.6 页面切换

- Tab 切换：无动画（即时切换）
- Stack 导航：iOS 默认右滑进入动画
- 底部抽屉（日历点击日期）：从底部滑入，可下滑关闭
- 周报弹窗：从底部滑入，不可下滑关闭（需点击按钮）

### 6.7 数据加载

- 首次加载：渐变骨架屏（浅灰→浅紫渐变占位），不使用旋转加载器
- 下拉刷新：iOS 原生刷新控件
